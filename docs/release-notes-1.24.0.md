# Wages Tracker 1.24.0

Track a second, third or further job within one account. Each job has its own locations, pay, shifts, fuel, extras, goals, weekly cycle and reminder preferences. Switch instantly or see combined earnings over one shared date range.

Set different hourly rates for locations, schedule pay changes and return a location to the job default. Shifts keep their recorded rates, including when pay changes later. Historical corrections require review.

PDF wage reports show each shift's hourly rate and wages, distinguish jobs and include fuel and extras separately. Export a personal combined summary or a report for one employer. Long location breakdowns wrap across pages.

Personal spending stays in one ledger with optional job tags. Admin gains job counts, pay history, recorded shift rates, job filters and reconciled earnings breakdowns. iOS reminders and Live Activities identify the correct job.

This release is intended for TestFlight validation. Signed build/upload details are recorded in [the delivery guide](ios-testflight-delivery.md) after delivery. It is not a public App Store submission.

See [the workspace guide](multi-job-workspaces.md) for migration behavior, calculation rules and the physical-device checklist.
